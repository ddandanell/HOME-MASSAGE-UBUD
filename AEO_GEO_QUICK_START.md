## Option 1: GitHub Copilot (Recommended)

### Prerequisites
- GitHub Copilot subscription
- Custom agents enabled in your repository

### Steps

1. **Open GitHub Copilot Chat** in your editor

2. **Invoke the AEO/GEO agent:**
   ```
   @aeo-geo-specialist Please optimize this content for AI search:
   
   [Paste your content here]
   ```

3. **Wait for the agent to respond** with the activation message:
   ```
   ✅ AEO AGENT READY. I will engineer your content into a dominant AI-search asset.
   ```

4. **Review the optimized output** which includes:
   - AEO Strategy Brief (what changed and why)
   - Fully optimized content in Markdown
   - Metadata block (title, description, slug, schema)

5. **Copy and use** the optimized content

### Example Invocation

```
@aeo-geo-specialist Transform this:

Massage therapy helps with pain. Many people find relief through 
regular massage sessions. It's beneficial for overall wellness.
```

**Agent will return:** Complete optimized version with zero-click snippet, comparison tables, specific data, metadata, etc.

## Common Mistakes to Avoid

### ❌ Don't Do This

1. **Skip the zero-click snippet** - It's critical for featured snippets
2. **Forget the comparison table** - AI models extract and display these
3. **Use marketing fluff** - "Revolutionary", "game-changing", etc.
4. **Write long paragraphs** - Keep to 3-4 sentences max
5. **Make vague claims** - Always add specific data
6. **Ignore metadata** - Essential for search visibility

### ✅ Do This Instead

1. **Always include 40-60 word snippet** after H1
2. **Create detailed comparison tables** with data
3. **Use precise language** with specific metrics
4. **Break into lists and bullets** for scannability
5. **Add percentages and numbers** to all claims
6. **Generate complete metadata** every time

## Troubleshooting

### "My content doesn't seem AI-optimized"

**Check:**
- Is the zero-click snippet present?
- Are there comparison tables?
- Is data specific (not vague)?
- Are entities bolded?

**Fix:** Re-run optimization with explicit checklist reminder

### "Output is too technical/robotic"

**Check:**
- Are there any examples or scenarios?
- Is there variation in sentence length?
- Are transition phrases present?

**Fix:** Add instruction: "Include concrete examples and vary sentence structure"

### "Missing metadata"

**Check:**
- Did Phase 4 complete?
- Is metadata block at the end?

**Fix:** Re-run with explicit request: "Generate complete metadata including title, description, slug, and Schema recommendations"
