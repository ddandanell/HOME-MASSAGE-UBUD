## 📝 Maintenance Notes

### To Update Pricing
Edit `/client/src/data/nailCareServices.ts`:
- Update `NAIL_CARE_SERVICES` array for service pricing
- Update `TRANSPORT_FEES` array for location pricing
- Changes propagate to all 24 area pages automatically

### To Add New Services
1. Add service to `NAIL_CARE_SERVICES` array
2. Optionally add to `FEATURED_NAIL_SERVICES` for area pages
3. Update /nail-care page manually if needed
4. Rebuild and deploy

### To Disable Nail Care on Specific Area
Edit area page file:
```typescript
<AreaPageTemplate 
  area={areaData} 
  showNailCare={false}  // Disable nail care section
/>
```
