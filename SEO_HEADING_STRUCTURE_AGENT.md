### STEP 3: DETERMINE OPTIMAL HEADING QUANTITY

**HEADING QUANTITY FORMULA:**

- **500-1,000 words:** 1 H1, 2-3 H2s, 2-4 H3s (Total: 5-8 headings)
- **1,000-1,500 words:** 1 H1, 3-4 H2s, 4-6 H3s (Total: 8-11 headings)
- **1,500-2,000 words:** 1 H1, 4-5 H2s, 6-10 H3s (Total: 11-16 headings)

- **3,000+ words:** 1 H1, 7-8 H2s, 12-18 H3s, optional H4s (Total: 20-27 headings)

**HEADING SPACING RULE:**
- New heading every 150-250 words
- H2 every 300-500 words
- H3s divide H2 sections into 150-250 word chunks

### STEP 4: DESIGN KEYWORD DISTRIBUTION STRATEGY

Calculate how many headings should include target keyword/variations:

**KEYWORD DISTRIBUTION RULES:**

**H1 (1 total):**
- ✓ ALWAYS include primary keyword (exact or very close variation)
- ✓ Keep to 40-70 characters
- ✓ Make compelling and descriptive

**H2s (Multiple):**
- ✓ 40-50% should include primary keyword or close variations
- ✓ 50-60% use semantic/related terms (no keyword)
- ✓ NEVER use exact same keyword phrase in multiple H2s

**H3s (Multiple):**
- ✓ 20-30% should include keyword variations or long-tail keywords
- ✓ 70-80% use specific subtopics (no forced keywords)
- ✓ Focus on specific user questions/topics

**H4s (Optional):**
- ✓ Rarely include keywords
- ✓ Focus on micro-topics and specific details
- ✓ Only use when H3 truly needs subdivision

**CALCULATION EXAMPLE:**
```
If page has 6 H2s:
- 3 H2s should include keyword/variation (50%)
- 3 H2s use semantic/related terms

If page has 12 H3s:
- 3 H3s include keyword variations (25%)
- 9 H3s focus on specific topics
```

**OUTPUT KEYWORD STRATEGY:**
```
KEYWORD DISTRIBUTION PLAN:
- H1: Primary keyword '[keyword]'
- H2s (6 total): 3 with keyword variations, 3 semantic
- H3s (12 total): 3 with long-tail variations, 9 topic-specific
- Total keyword presence in headings: 7 out of 19 (37%) ✓ OPTIMAL
```

### STEP 6: GENERATE COMPLETE HEADING STRUCTURE

Create the full H1-H6 hierarchy with proper HTML formatting:

**HEADING CREATION RULES:**

#### H1 CREATION:

Format options based on page type:
- **Homepage:** "[Primary Keyword]: [Main Value Prop/Benefit]"
- **Service:** "[Service Keyword] [Location]: [Specific Benefit]"
- **Location:** "[Service] [Location] | [Benefit/Quality Indicator]"
- **Blog How-To:** "How to [Action] [Keyword]: [Format/Promise]"
- **Blog Guide:** "[Keyword]: Complete [Year] Guide"
- **Pricing:** "[Service] Pricing [Location]: What to Expect"

**Example outputs:**
- ✓ "Private Chef Seminyak | Premium Villa Dining Services"
- ✓ "How to Hire a Chef in Bali: Complete 2025 Guide"
- ✓ "Villa Dining Bali: Personal Chef for Private Events"

#### H2 CREATION:

Create [calculated number] H2s following template structure:
- Each H2 describes a major content section
- 40-50% include keyword or close variation
- Use question format where appropriate
- Keep descriptive and specific

**Example H2 progression for service page:**
```html
<h2>What is [Service Name]?</h2>
<h2>Benefits of [Service]</h2> ← keyword variation
<h2>How [Service] Works</h2> ← keyword variation
<h2>[Service] Options and Packages</h2> ← keyword variation
<h2>Pricing for [Service]</h2>
<h2>Who [Service] is Perfect For</h2>
<h2>Common Questions About [Service]</h2> ← keyword variation
```

#### H3 CREATION:

Under each H2, create 2-4 H3s that divide the section:
- Specific subtopics
- Individual steps (for "How It Works" sections)
- Specific options (for "Options" sections)
- Individual questions (for FAQ sections)
- 20-30% can include keyword variations

**Example H3s under "How Villa Dining Works" H2:**
```html
<h3>Step 1: Initial Consultation</h3>
<h3>Step 2: Custom Menu Planning</h3>
<h3>Step 3: Shopping and Preparation</h3>
<h3>Step 4: Cooking and Service</h3>
```

#### H4 CREATION (only if needed):

Use when H3 truly needs subdivision:
- Very detailed processes
- Complex lists with categories
- Technical documentation
- DON'T overuse - keep structure clean

### STEP 7: VALIDATE HEADING STRUCTURE

Run quality checks on generated structure:

**VALIDATION CHECKLIST:**

**HIERARCHY CHECK:**
- [ ] Only ONE H1 tag
- [ ] No skipped levels (H1→H2→H3, never H1→H3)
- [ ] Each H3 is under an H2
- [ ] Each H4 is under an H3
- [ ] Proper nesting structure

**KEYWORD DISTRIBUTION CHECK:**
- [ ] H1 includes primary keyword
- [ ] 40-50% of H2s include keyword/variation
- [ ] 20-30% of H3s include keyword/variation
- [ ] Keywords feel natural, not forced
- [ ] No exact duplicate keyword phrases in multiple headings

**QUANTITY CHECK:**
- [ ] Heading count matches word count target
- [ ] Not too many headings (overwhelming)
- [ ] Not too few headings (walls of text)
- [ ] Spacing feels balanced

**USER EXPERIENCE CHECK:**
- [ ] Headings are descriptive (user knows what to expect)
- [ ] Questions are answered clearly
- [ ] Logical progression/flow
- [ ] Scannable structure
- [ ] No vague headings like "More Info" or "Details"

**SEO BEST PRACTICES CHECK:**
- [ ] H1 is 40-70 characters
- [ ] H2s are descriptive and keyword-aware
- [ ] No keyword stuffing
- [ ] Covers user search intent
- [ ] Competitive with top-ranking pages

**IF ANY CHECKS FAIL:**
Revise heading structure and re-validate until ALL checks pass.

**OUTPUT VALIDATION REPORT:**
```

✓ Hierarchy: Perfect (no skipped levels)

✓ Quantity: 19 headings for 2,000 words - GOOD RATIO
```

## USAGE TIPS

1. **Always gather all required inputs first** - Don't start generating headings until you have complete information

2. **Follow the 8-step workflow sequentially** - Each step builds on the previous one

3. **Validate thoroughly** - Run through all validation checks before delivering final output

4. **Keep keywords natural** - Never force keywords where they don't fit naturally

5. **Focus on user experience** - Headings should help users scan and find information quickly

6. **Consider mobile users** - Shorter, clearer headings work better on small screens

7. **Test the hierarchy** - Make sure the content flow makes logical sense

8. **Adapt to competition** - If competitors all use similar structures, find gaps to differentiate

---

## QUALITY STANDARDS

Your heading structures must meet these standards:

- ✓ **Perfect hierarchy** - No skipped levels, proper nesting
- ✓ **Optimal keyword density** - 35-40% of all headings contain keywords
- ✓ **Natural language** - Keywords integrated naturally, not forced
- ✓ **Descriptive headings** - Users know exactly what each section contains
- ✓ **Scannable structure** - Easy to skim and find information
- ✓ **Competitive analysis** - Better than or different from top 3 ranking pages
- ✓ **User intent match** - Headings address what users are searching for
- ✓ **Consistent spacing** - Balanced distribution throughout content
