# Landing Page SEO Checklist
## Pre-Launch Verification for HomeMassageUbud.com Landing Pages

**Date Created**: January 1, 2026  
**Purpose**: Ensure all new landing pages meet SEO best practices before publication  
**Use**: Check each item before launching any new landing page

---

## 📋 On-Page SEO Elements

### Meta Tags
- [ ] **Title Tag** is 50-60 characters (including brand name if space allows)
- [ ] **Title Tag** includes primary keyword naturally
- [ ] **Meta Description** is 150-160 characters
- [ ] **Meta Description** includes primary keyword
- [ ] **Meta Description** includes clear CTA (e.g., "Book now", "WhatsApp us")
- [ ] **Meta Description** is unique (not duplicated from other pages)
- [ ] **Meta Keywords** tag includes primary + 3-5 secondary keywords (if used)

### Headings Structure
- [ ] **H1 tag** is present and unique on page
- [ ] **H1 tag** includes primary keyword naturally
- [ ] **H1 tag** is compelling and benefit-focused (not just keyword stuffing)
- [ ] Only ONE H1 tag per page
- [ ] **H2 tags** are used for main sections (6-8 recommended)
- [ ] **H2 tags** include keyword variations naturally
- [ ] **H3-H6 tags** are used for subsections hierarchically
- [ ] Heading hierarchy is logical (H2 → H3 → H4, no skipping levels)

### Content Quality
- [ ] **Word count** is 800-1200 words minimum (per brief requirements)
- [ ] Content is 100% unique (run through plagiarism checker)
- [ ] **Primary keyword** appears 5-8 times naturally throughout content
- [ ] **Primary keyword** appears in first 100 words
- [ ] **Secondary keywords** are distributed naturally (3-5 keywords, 2-4 times each)
- [ ] Content addresses user search intent clearly
- [ ] Benefits are emphasized over features
- [ ] Content includes location-specific details (not generic)
- [ ] No keyword stuffing or unnatural phrasing
- [ ] Content is scannable (short paragraphs, lists, subheadings)

### Internal Linking
- [ ] **5-8 internal links** to related pages (per brief requirements)
- [ ] Internal links use descriptive anchor text (not "click here")
- [ ] Internal links are contextually relevant
- [ ] Links to: Related services, treatment pages, area pages
- [ ] Links open in same window (not new tab for internal links)
- [ ] All internal links are working (no 404 errors)
- [ ] Breadcrumb navigation is present and functional

### URL Optimization
- [ ] **URL slug** is clean and readable (e.g., /services/couples-villa-massage)
- [ ] **URL slug** includes primary keyword
- [ ] **URL slug** uses hyphens (not underscores) to separate words
- [ ] **URL slug** is lowercase
- [ ] **URL slug** is short and concise (3-5 words ideal)
- [ ] No dynamic parameters in URL (?, &, =)
- [ ] Canonical tag points to correct URL

### Images
- [ ] All images have descriptive **alt text**
- [ ] **Alt text** includes keywords naturally (no stuffing)
- [ ] **Alt text** describes the image for accessibility
- [ ] Images are optimized for web (compressed, appropriate size)
- [ ] Images have descriptive filenames (not IMG_1234.jpg)
- [ ] At least 3-4 relevant images per page
- [ ] Images are responsive (work on mobile devices)

---

## 🔗 Technical SEO

### Page Performance
- [ ] Page loads in under 3 seconds on mobile
- [ ] Page loads in under 2 seconds on desktop
- [ ] Images are lazy-loaded where appropriate
- [ ] CSS and JavaScript are minified
- [ ] No render-blocking resources
- [ ] Page passes Core Web Vitals (LCP, FID, CLS)

### Mobile Optimization
- [ ] Page is mobile-responsive (test on multiple devices)
- [ ] Text is readable without zooming on mobile
- [ ] Buttons and links are easily tappable (44x44px minimum)
- [ ] No horizontal scrolling on mobile
- [ ] WhatsApp CTA is prominent and functional on mobile
- [ ] Mobile viewport meta tag is present

### Crawlability
- [ ] Page is not blocked in robots.txt
- [ ] Page is included in XML sitemap
- [ ] No noindex meta tag (unless intentional)
- [ ] No nofollow on important internal links
- [ ] Canonical tag is present and correct
- [ ] Page is accessible to Googlebot (test in Search Console)

### HTTPS & Security
- [ ] Page is served over HTTPS (not HTTP)
- [ ] SSL certificate is valid
- [ ] No mixed content warnings (HTTP resources on HTTPS page)
- [ ] External links to reputable sources only

## 📊 Schema Markup

### Service Schema
- [ ] **Service schema** is present in JSON-LD format
- [ ] Service schema includes: serviceType, name, description
- [ ] Service schema includes provider (organization details)
- [ ] Service schema includes areaServed (locations)
- [ ] Service schema includes offers (price information)
- [ ] Service schema includes aggregateRating (if applicable)
- [ ] Schema validates without errors (test at schema.org validator)

### FAQ Schema
- [ ] **FAQ schema** is present for FAQ section
- [ ] FAQ schema includes all questions and answers from page
- [ ] FAQ schema is properly formatted (test at schema.org validator)
- [ ] FAQs are also visible in HTML (not schema-only)

### Breadcrumb Schema
- [ ] **Breadcrumb schema** is present
- [ ] Breadcrumbs match visual breadcrumb navigation
- [ ] Position property increments correctly (1, 2, 3...)
- [ ] Breadcrumb validates without errors

### Additional Schema (as applicable)
- [ ] **AggregateRating schema** if testimonials/reviews present
- [ ] **Review schema** for individual testimonials
- [ ] **PriceSpecification schema** for pricing details
- [ ] All schema types validate at schema.org validator

## 🎯 Conversion Optimization

### Call-to-Action (CTA)
- [ ] **Primary CTA** (WhatsApp) appears above the fold
- [ ] **Primary CTA** appears at least 3 times on page (hero, mid-page, footer)
- [ ] CTA buttons are visually prominent (contrasting color)
- [ ] CTA copy is action-oriented ("Book Now", "WhatsApp Us")
- [ ] **Secondary CTAs** are present (pricing, packages, etc.)
- [ ] All CTA links are functional and correct
- [ ] WhatsApp link includes pre-filled message (optional but recommended)

### Trust Signals
- [ ] Certifications/qualifications are mentioned
- [ ] Number of clients served is displayed
- [ ] Star rating is visible (4.8★+ ideally)
- [ ] Same-day booking availability is mentioned (if applicable)
- [ ] Therapist credentials are highlighted
- [ ] Payment methods are clear

### Social Proof
- [ ] At least 3 client testimonials are present
- [ ] Testimonials include first name + location/country
- [ ] Testimonials are specific (not generic praise)
- [ ] Partner logos displayed (if applicable: yoga studios, surf camps, etc.)
- [ ] "Featured in" or "Recommended by" mentions (if applicable)
- [ ] Review count is displayed with rating

### User Experience
- [ ] Contact information is easy to find
- [ ] Pricing information is transparent (not hidden)
- [ ] Service areas are clearly listed
- [ ] FAQs address common objections/concerns
- [ ] Page has clear visual hierarchy
- [ ] No intrusive popups that harm UX

## 🔍 Pre-Launch Testing

### Content Review
- [ ] Read entire page aloud (sounds natural and conversational)
- [ ] No spelling or grammar errors (use Grammarly or similar)
- [ ] Tone matches brand guidelines (warm, professional, tourist-friendly)
- [ ] No overly technical massage terminology
- [ ] Local details are accurate (place names, distances, etc.)
- [ ] Pricing is current and accurate
- [ ] Contact information is current (+62 phone number, WhatsApp link)

### Link Testing
- [ ] All internal links work (no 404s)
- [ ] All internal links go to intended pages
- [ ] WhatsApp link opens WhatsApp correctly
- [ ] External links (if any) open in new tab
- [ ] Breadcrumb links are functional
- [ ] Footer links work correctly

### Browser Testing
- [ ] Page displays correctly in Chrome
- [ ] Page displays correctly in Safari
- [ ] Page displays correctly in Firefox
- [ ] Page displays correctly in Edge
- [ ] No console errors in any browser

### Device Testing
- [ ] Test on iOS mobile (iPhone)
- [ ] Test on Android mobile
- [ ] Test on tablet (iPad or Android)
- [ ] Test on desktop (1920x1080)
- [ ] Test on desktop (1366x768)

### SEO Tools Validation
- [ ] Run page through Google PageSpeed Insights (score 80+ mobile, 90+ desktop)
- [ ] Test structured data at schema.org validator (no errors)
- [ ] Check mobile-friendliness at Google Mobile-Friendly Test
- [ ] Run through SEO checker (Ahrefs, SEMrush, or similar)
- [ ] No broken links detected by crawler
- [ ] Page title and meta description preview look good in SERP simulator
